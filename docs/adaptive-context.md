# 接近请求上限再压缩

更新：2026-10-22。启用确定性上下文压缩后，默认 `trigger_ratio` 从 `0` 调整为 `0.8`：完整请求达到字节上限的 80% 才尝试省略旧观察。没有开启 `compact` 时仍不压缩；硬请求上限、最近消息保护、失败保留和保存的完整历史保持原有规则。没有自动摘要请求或额外模型调用。

```toml
[context]
compact = true
trigger_ratio = 0.8 # 新默认；0 为旧的每轮尝试省略模式
```

CLI 可使用 `--compact-context --context-trigger-ratio 0.8`。显式 `0`、profile/项目层和 CLI 优先级仍有效。CLI 和 TUI 的 `/context` 按当前设置预览对话，并列出系统提示、用户侧消息、助手侧消息、工具结果、工具定义和其余封装的实际协议字节。负的 `remaining_bytes` 表示超限；若尚未开启压缩，超限时也会显示启用后的预计结果。`/compact` 显示强制压缩预览，确认后启用按配置阈值压缩。预览以当前对话和第一轮模型请求为基准。后续读取、编辑、引导、附件或恢复时的版本信息都可能改变大小。这些数值量化请求字节，模型 token 用量另见 `/usage`。 [配置](configuration.md)

## 修正依据

[真实 grep 运行](live-evaluation-grep-20261022.md)启用了压缩且比例为旧默认 0。离线使用原有 12 个请求前缀重建运行元数据、工具定义和压缩投影，逐个复现已记录的全部发送字节数。第 12 个请求压缩前只有 40492 字节，远低于 131072 字节硬上限；每轮裁剪仍把可见读取正文从 12405 字节降到 6005 字节，可见读取标识从 5 个降到 0 个。原始私有历史未改变。

同一轨迹只把比例改为 0.8 时，12 个前缀全部在原上限内且均不触发裁剪。它保留了已经取得的源码和检索信息；这是确定性的请求证据，不是模型成功率测量。[离线数值](benchmarks/adaptive-context-replay-20261022.json)不包含正文、路径或推理。

固定 OpenCode `dev@9d90d892dcbfc52b47e95b2ea31b8aba877128fd` 的 [compaction.ts](https://github.com/anomalyco/opencode/blob/9d90d892dcbfc52b47e95b2ea31b8aba877128fd/packages/core/src/session/compaction.ts)在自动路径中先执行 `due(context, calculateCeiling(...))`，未达到条件则 skipped。Sprig 借鉴先检查压力再压缩的安排，继续使用自己的有界确定性省略，不复制其 token 估计或模型摘要请求。

保留原始读取标识也不产生授权：文件编辑仍检查读取版本、路径/隐私、逐次批准及批准后的文件状态；命令导致的失效和跨进程恢复规则不变。阈值达到后，原有历史快照仍去掉不可作为当前读取证明的标识；显式 0 的旧行为继续可重现。

## 验证范围

三协议 HTTP/SSE 回归让模型先完成五次文件读取，再从实际第六次请求中取得第一次读取的标识、提出编辑，并以另一次新批准运行固定验收。预算内应保留原证据，保存历史不被改写。另覆盖显式 0、强制预览、压缩关闭、设置优先级；原有读取保留/折叠机制测试显式指定 0，继续按原预算验证裁剪后的安全边界。

单次真实 Flash-2 运行使用同任务、同 12 轮预算和显式 0.8，从 635/642 推进到 640/642，公开异常契约通过，仍未完成。该运行发生在默认值修改之前，使用的正是已有配置开关。不同运行的服务状态和模型选择不同，不能把单次变化全部归因于阈值，也不能宣称总体能力达标。完整轨迹另列于[实测记录](live-evaluation-adaptive-20261022.md)。

保留更多上下文会增加发送字节，显式 0 可保留更积极的省略策略；不宣称费用更低。远程 CI 按用户要求暂停到 2026-11-01，之后仍先确认账户限制和旧 gate；本地结果、源码摘要和平台跳过见[验证记录](benchmarks/adaptive-context-20261022.json)。
