# 跨文件符号重命名

在已配置的 LSP 上使用：

```text
/lsp rename cpp "src/main.cpp" 12 8 新名称
```

模型也可调用 `lsp(action="rename", server="cpp", path="src/main.cpp", line=12, column=8, new_name="新名称")`。位置沿用 1 起始 Unicode 行列，内部转换为 UTF-16。新名称最多 256 个字符/1024 个 UTF-8 字节，拒绝控制字符与已配置凭据；具体语言的名称合法性由服务器验证。可省略模型工具的 server，但后缀必须唯一匹配一个已配置服务器。

需要启用 `lsp`、`read_file` 和 `edit_file`，只读模式拒绝执行。禁用 edit_file 后，模型 LSP schema 移除 rename，其他查询保持可用。CLI/TUI 的本地命令不请求模型；成功修改后原任务仍未重新验收，用户可以明确运行 `/verify` 或提交下一请求。

## 批准和写入

第一层批准涵盖明确的服务器 argv/cwd、环境名称、已打开源码快照、位置、新名称和 RPC 预算。支持 `renameProvider`，服务器声明 prepareProvider 时先请求 prepareRename；准备被拒绝、失败、过期或超限均不提交文件写入。

接收 WorkspaceEdit 后，检查全部目标、当前完整源码、UTF-16 范围和编辑数量。随后关闭这次服务器连接，再复用既有独立文件批次预检和逐文件完整差异批准。批次初始预检失败时没有重命名写入；每次批准后复查全部剩余目标，后面的文件在批准期间变化也会阻止当前写入。文件审阅等待不继续消耗已完成 RPC 的期限，归属、取消和配置检查持续生效。

RPC 批准不授权文件写入；每个文件分别批准。拒绝或错误停止后续文件，已经完成的前缀保持，报告实际确认数量。取消不会自动重试。写入结算不确定时保留 pending 备份和不确定状态；归属改变也保留已经确认的前缀观察。后续需检查实际文件和恢复记录，不重放旧 RPC、旧批准或未结算写入。

文件使用普通编辑的路径/隐私/凭据检查、审批后身份与完整内容复查、原子替换及私有备份；没有新增服务器写入通道。可用 `/changes`、`/undo`、`/redo`，同一批次也可逐文件批准 `/undo-batch`、`/redo-batch`。恢复受既有历史容量、外部修改和未结算状态约束，不承诺跨文件事务或无限保留。

## 协议和限制

接受 `changes` 或 `documentChanges`，两者都有时按标准优先后者。只支持已有文件的普通 TextEdit；文件创建/移动/删除、变更注解、服务器主动 workspace/applyEdit、executeCommand 和动态注册均拒绝。最多 16 个目标文件、合计 512 处编辑，每份源码和结果最多 512 KiB，原 1 MiB RPC 帧、总期限、通知与进程限额保持。

所有目标都先检查；不丢掉不安全目标后执行剩余部分。重复/别名 URI、越界和私有路径、非法或重叠范围、代理对切分、过期版本、超限及凭据正文均拒绝。多个同位置插入保持数组顺序，未修改字节、BOM 和 CR/LF 物理边界保持；newText 的换行按服务器提供的字面值应用，不统一转换。

带版本的 TextDocumentEdit 必须对应本连接当前已同步的文档版本和源码摘要。未标版本的目标在收到提案后读取、绑定当前完整字节，结果列出 `unversioned_target_files`；这不能证明服务器索引基于同一快照。完整差异批准和应用版本检查仍不证明语义正确或项目引用完整，应审阅并测试。

完整成功的模型工具调用进入既有编辑后固定检查；最终验收仍独立运行、逐次批准。部分完成、拒绝、错误和不确定结果不作为完整编辑成功。重命名结果直接返回有界计数与批次标识，不缓存成可重放命令；`/lsp result` 继续只分页查询观察。

本地验证包含协议 peer、三协议 JSON/SSE、Enter TUI 和已安装真实 clangd 的两文件 C++ 夹具。真实夹具确认目标命名空间跨文件变化、无关同名符号保持、CRLF 和精确撤销/重做；复现命令：

```text
uv run --locked python scripts/verify-lsp-rename.py --clangd <已安装的 clangd> --approve-disposable
```

该选项仅批准脚本列明的一次性夹具操作，不安装程序、不调用模型。源码取舍见[调研](research/lsp-rename-20261029.md)，完整本地回归、失败和身份见[验证记录](benchmarks/lsp-rename-20261029.json)。远程原生 CI 继续待解禁，不以本地 WSL 或平台跳过替代；这些检查不构成真实编程任务成功率结论。
