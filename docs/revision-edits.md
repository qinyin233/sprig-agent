# 绑定文件版本的按行编辑

模型仍通过 `edit_file` 请求修改，用户仍审阅完整 diff 并逐次批准。新增的 `sha256 + line_edits` 模式减少重复发送旧正文，适合替换较长代码块；原有 `old/new` 和 `edits` 继续支持。小片段替换不一定更省参数。

## 工具协议

模型先用 `read_file(path, offset, limit)` 检查目标行。范围读取完整校验至多 8 MiB 的文件，然后返回整个文件原始 UTF-8 字节的 `sha256`。完整、未截断的普通读取也返回该值；普通截断前缀不返回它。包含已知配置凭据的内容不暴露哈希，避免把脱敏内容转为可验证的凭据指纹。

随后请求一个已有文件的编辑，包含：

| 字段 | 含义 |
| --- | --- |
| `path` | 工作区相对 POSIX 路径，Windows 也用 `/` |
| `sha256` | 原样复制刚才读取结果的 64 位小写十六进制摘要，不能猜测 |
| `line_edits` | 1–32 个 `{start_line, end_line, new}` 对象 |

行号以原始版本为准，1-based、两端包含；物理行只按 CR/LF 划分，Unicode U+2028 等不改变行号。`end_line=start_line-1` 表示在该行前插入；在 N 行文件末尾追加用 `(N+1, N)`。空文件允许 `(1, 0)`。

`new` 按字面替换整行，包括换行符；需要 LF/CRLF 时须明确包含。程序不自动添加或转换换行，原有 UTF-8 BOM 保留。最后一行没有换行时，追加内容可能需要显式的前导换行。模型应先读取完整相关行，不能把截断输出当作完整文件。

所有范围对应原始文件，互相重叠、同一位置竞争插入、越界、混用三种编辑模式都会拒绝。文件和合计新文本各受 512 KiB 上限约束。

## 安全事务

1. 检查工具开关、只读、路径、隐私、目录规则和取消状态。
2. 读取当前文件，核对整个文件的 SHA；过期时不显示审批、不修改，要求重新读取。
3. 校验全部范围并构造完整结果，再执行 UTF-8、凭据和大小检查。
4. 展示实际旧文件与结果的完整 diff，默认拒绝。
5. 获批后重新检查文件身份/字节、隐私规则、AGENTS.md 和取消，再一次写入并记录精确撤销数据。

成功返回结果版本的 SHA。审批期间其他编辑器改动文件会阻止本次写入。不会因相同行号或相同 mtime 接受过期版本。撤销/重做仍逐次批准；只读和禁用编辑也覆盖新模式。

显式上下文压缩只省略已批准完成的旧编辑正文，保存的历史保留原始参数；失败、拒绝及最近消息不省略。

## 输出上限与失败恢复

请求提示会注明显式设置的单次输出 token 上限，要求模型缩小提案。`finish_reason=length` 始终拒绝整个响应，任何部分工具意图均不执行；不会自动提高预算或重试。

发生已确认的输出上限错误时，会话只加入固定的应用状态说明，不保存部分响应。用户显式继续后，模型可据此缩小提案；这条说明不构成操作批准。

请求统计新增允许列表中的 `finish_reason`、`error_code` 和累计 `failures`，区分输出上限、HTTP、超时、TLS、未完整结束的流、请求预算及无效协议等。陌生服务端原因只记 `other`，不记录原文。用量仍以服务实际报告为准，不由结束原因推算。

## 已验证与尚未验证

回归覆盖真实回环 HTTP 的读取/编辑/固定命令验收、重复行、CRLF/BOM/Unicode、过期摘要、审批期间变更、只读、凭据、大小、取消、撤销和上下文压缩。

[Click 工具对照](benchmarks/click-line-edit-tools-20261015.json)将同一已知参考补丁应用三次：两种模式均修改 4 个文件、获得 4 次审批、逐字节复现相同源码，并通过 642 项固定检查。编辑参数从 7026 字节降至 3059 字节，减少 56.46%。按行模式另有 4 次版本读取，报告单列其时间和输出；不能把编辑时间单独当作总耗时，也不能据此推断 token、费用或模型任务成功率。该记录带有当时工作区 dirty 标记及实际源码摘要。

普通范围读取是其他成熟 agent 已有的基础能力，见 [OpenCode 工具说明](https://opencode.ai/docs/tools/) 和 [Pi read 实现](https://github.com/badlogic/pi-mono/blob/main/packages/coding-agent/src/core/tools/read.ts)。本轮新增版本绑定的整行提案与状态反馈，不代表完成 LSP、语义引用或完整隔离执行。
