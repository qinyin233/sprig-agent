# 读取版本绑定的整行编辑

`read_file` 完整校验文件后，返回 `sha256` 和一个简短的 `read_id`。模型使用独立的 `edit_lines` 工具，不必把 64 位摘要复制到多种可选编辑参数里：

```json
{"path":"src/example.py","read_id":"r0123456789ab-1","edits":[{"start_line":3,"end_line":4,"new":"replacement\n"}]}
```

行号从 1 开始，结束行包含在内；插入使用 `end_line=start_line-1`。每次最多 32 段，不能重叠；替换文本明确包含所需 LF/CRLF，不自动转换换行。512 KiB 写入上限、完整 diff、新批准、审批后内容/文件版本复查、精确撤销继续适用。短标识只关联路径与完整 SHA-256，不提供写入授权。

范围读取仍扫描整个受限文件（最多 8 MiB）；返回窗口可以有后续行，但当前物理行必须完整。普通截断字节前缀、局部物理行、二进制、包含已知凭据或被隐私规则排除的内容均不发放标识。编辑前仍应读取全部相关行。

标识只在当前工具实例的一次 agent 运行内有效，最多保留 128 个文件版本。相同路径与摘要复用标识；不同路径不能互用。以下情况需重新读取：

- 对该文件完成写入、撤销或重做后。
- 任何获批命令启动前后，包括启动失败；被拒绝的命令不清除标识。
- 新任务、继续、恢复或工具实例关闭后。保存的对话可能包含旧标识，恢复不会重新授权它们。
- 标识因有界缓存淘汰而不再存在。

外部更改使旧摘要失效，停在审批之前；审批期间更改也拒绝覆盖。其他文件的编辑不使本文件标识自动过期。原来的 `edit_file(old,new)` 与精确多片段替换保留；旧 `sha256+line_edits` 运行接口仍兼容，模型 schema 推荐使用独立 `edit_lines`。

`[tools].edit_lines=false` 可单独关闭它；`edit_file=false` 或只读模式同时禁止两种写入接口。项目层不能借启用 `edit_lines` 绕过用户禁用的 `edit_file`。

版本参数错误返回固定分类：`missing_revision`、`invalid_revision`、`unknown_read_id`、`stale_revision`；无效参数不会被替换成当前版本后继续写入。基准诊断只记录这些固定状态与版本是否可用，不发布摘要、短标识、路径或原始参数。

这项接口源于[20 轮 Click 失败记录](live-evaluation-20261016.md)后续的离线改进。原始模型第二次编辑的原始参数未保留，不能确定是缺失摘要还是格式错误；离线接口回归不能证明该真实任务已修复或模型编码能力提高。
