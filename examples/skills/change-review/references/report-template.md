# Review report

Lead with the observed result. For each actionable finding, state:

- The concrete trigger and affected source location.
- What happens and why it violates the requested behavior.
- Evidence from code inspection or an explicitly approved validation.

If implementing a fix, describe the resulting behavior and relevant validation. Separate passing checks, platform skips, and behavior that has not been exercised. If no actionable finding remains, say so and state the practical limits of the review.
