# 网页文档读取与分页

Sprig 可以读取公开的 HTTP(S) 文本文档，让模型查阅接口说明、发行说明或源码页面。默认关闭；启用不会立即联网。每个新 URL 请求都要在应用审批界面单独批准。网页是外部数据，不是项目指令、操作许可或检查结果。

## 开启与使用

在用户 `config.toml` 或可信 profile 中设置：

```toml
[web]
enabled = true

[tools]
web_fetch = true
```

也可以启动时使用 `uv run --locked sprig --web`，用 `--no-web` 覆盖配置。`--disable-tool web_fetch` 和 `[tools] web_fetch=false` 进一步禁用；项目配置不能声明 `[web]`，避免仓库开启网络能力。只读模式在执行层阻止联网及此工具，不只隐藏模型定义。此开关和工具策略绑定会话，切换模型不能放宽。

启用后，三个模型协议均获得 `web_fetch` 函数工具。提供 `url` 可发起一次请求；提供返回的 `result_id` 和 `next_offset` 则读取同一份内存快照，不再请求服务器。`offset` 是 UTF-8 字节位置，必须落在字符边界。`format="text"` 默认提取 HTML 可见文本，保留代码缩进、基本块边界并附最多 64 个链接；链接不会自动访问。`format="raw"` 返回原始文本源码，仍视为不可信数据。提取不是浏览器渲染，不保证完整重现 CSS、表格、可访问性树或动态页面。

TUI 和连续 chat 也提供本地命令：

```text
/web
/web https://docs.python.org/3/library/html.parser.html
/web result web-<ID> <UTF8偏移>
```

第一条只显示开关及缓存数量/字节；后两条读取或翻页。命令补全和帮助中可发现入口。本地查看不会暗中上传到模型，也不计为模型完成任务。普通输入仍 Enter 发送，执行中仍可输入引导；审批期间的新要求使旧提案被拒绝，网络操作取消或退出后不重放。

## 地址、认证与请求边界

只使用 HTTP GET，固定请求头，不继承模型供应商认证头、系统 cookies、`.netrc`、代理环境或配置代理。HTTPS 保留系统证书和主机名验证。需要代理、登录、浏览器交互或远程上传的站点不在本功能范围。HTTP 明文 URL 会在批准内容中显示；GET 可能在远端产生状态或访问记录，批准并非匿名访问或无副作用保证。

URL 禁止 userinfo、控制/空白字符、反斜线及 IPv6 scope；已知配置凭据及常见 token/password 类查询参数在发送前拒绝。Unicode 主机按 IDNA、路径/查询按 URL 编码规范化，fragment 不发送。无法识别任意自定义签名或秘密参数，因此仍须检查批准中的完整 URL。

IP 字面量和 DNS 返回的**全部**地址都需满足公开地址策略；拒绝回环、私网、link-local、组播、metadata、映射/过渡地址，以及保守排除的协议专用/文档地址。为减少不同 Python 版本的分类差异，IPv4 额外排除 `192.0.0.0/24`、`192.88.99.0/24`；IPv6 限于 `2000::/3` 并排除 `2001::/23`、`2001:db8::/32`、`2002::/16` 和 `3fff::/20`。这可能拒绝部分合法的特殊用途公网地址。

连接直接消耗这一次已检查的 sockaddr 列表，不二次按主机解析；HTTPS 仍使用原主机验证证书。混合公网/非公网 DNS 结果全部拒绝。同步系统 DNS 无法强制中断，但解析返回后先检查取消和期限，迟到结果不能启动连接。这不是 OS 网络沙箱，也无法阻止用户独立批准的 `run` 或 MCP 服务访问其他地址。

所有重定向均停止；可显示安全规范化后的 `redirect_url`，访问它需要另一次新批准。若完整目标使错误说明超出输出限额，则省略地址并标记 `redirect_url_omitted`，不返回截断 URL。HTTP 错误、证书错误、连接失败、超时、取消和部分正文都不自动重试。不会降级 TLS、更换 User-Agent 绕过站点限制、安装浏览器、加载脚本或请求子资源。

## 限额和生命周期

- 单次下载最多 2 MiB，明确拒绝超大 Content-Length、重复/冲突 framing、超过配额的 chunked 正文和不完整消息；失败不保留部分结果。
- 只接受文本类 MIME、JSON/XML/JavaScript 等文字内容，限定常见 UTF/ASCII/Latin 编码；不做 PDF、图片或二进制传输。请求 `identity`，服务器返回压缩体时拒绝，避免解压膨胀。
- 空闲期限为 `min(request_timeout 或 timeout, 30秒)`，总期限为 `min(request_deadline, 120秒)`。复用现有可轮询取消的传输；连接、读体和提取共用期限，阶段间不重置。系统 DNS 的阻塞限制见上文。
- HTML 提取限制嵌套、文本量和 token 回调数量；去掉 script/style/head/iframe/object/template 及明确 hidden 内容。raw 不执行内容。HTML 链接和提取最多产生 4 MiB 文本。
- 当前对话最多 8 个快照，总正文 8 MiB，超限淘汰最旧使用项。显示页包含 URL、MIME、格式、脱敏后 SHA-256、范围、续读偏移和不可信标记，完整 JSON 不超过 `min(max_output,16384)`；不足以容纳说明时明确失败。
- 快照仅在内存，保存会话不单独保存网页正文、cookies 或连接。正常模型工具结果中已显示的片段仍会随可选历史保存；私有保存不加密。本地命令输出不自动写入模型历史。
- 缓存先脱敏，分页时复查新增凭据；变化则使句柄失效。新对话、恢复、历史分支、模型切换和退出清空缓存。历史中的旧句柄不能重建数据或自动重新联网。

网页快照描述获取时的内容，不证明文件当前状态或代码通过测试。页面要求写文件、执行命令、发送秘密或跳过检查时，仍受原有工具策略和逐次审批约束。

## 源码依据与验证范围

阅读固定 OpenCode `9d90d892dcbfc52b47e95b2ea31b8aba877128fd` 的 [`webfetch.ts`](https://github.com/anomalyco/opencode/blob/9d90d892dcbfc52b47e95b2ea31b8aba877128fd/packages/core/src/tool/plugin/webfetch.ts)：上游有 HTTP(S) 文本格式、下载上限、HTML 转换和超时，以及特定 403 challenge 的 User-Agent 重试。Sprig 参考文本文档处理思路，保留自己的逐次审批，使用公开地址检查、内存分页和零自动重试；没有复制上游实现或声称所有网页行为相同。

`tests/test_web_fetch.py` 使用真实回环 HTTP/TLS、实际 Textual/CLI、三协议 HTTP/SSE 和固定子进程检查。生产代码没有私网白名单选项；回环测试仅在测试作用域放行该 fixture 的地址，另独立验证私网/混合 DNS 拒绝、单次解析直连和证书验证。固定模型回复不代表新的真实编码成绩。

按用户要求，2026-11-01 前不调度、不重跑 GitHub Actions，推送标记 `[skip ci]`。本地 Windows/WSL 的通过及平台跳过单独记录，不能代替原生 CI 或完整 Python/macOS 矩阵；到期后先核对账户限制和先前必要 gate。

最终冻结源码的主测试两端各 1141 项：Windows 1122 通过、19 平台跳过，WSL 1118 通过、23 跳过；Windows Python 3.11 相关 58 项、两端 mini SDK 各 25 项通过。隔离安装的 wheel 核对 59 个模块，80×24 TUI 通过三次独立批准完成网页读取、真实文件写入和应用固定检查，并验证缓存分页与私有恢复不重新联网。长重定向说明超出 max_output 的问题先由真实用例复现，修复为省略完整地址后才计入本次最终验证；修复前的通过不能代表最终源码。没有外部模型请求或本批远程 CI，公开文档访问仍受当前非公网 DNS 结果限制。 完整范围见[机器记录](benchmarks/web-fetch-20261022.json)。
