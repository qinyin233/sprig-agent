# 可复用任务模板

在私有用户 `config.toml` 中定义常用任务，启动后可在 TUI/chat 里用 `/名称 参数` 发送：

```toml
[prompts.review]
description = "审查修改并提出检查方案"
template = """检查当前代码的正确性和测试缺口。
范围：$ARGUMENTS
先读取相关文件，再解释发现并提出修改。"""

[prompts.explain]
description = "解释一个文件或概念"
template = "解释 $1，给出具体例子。"
```

例如输入 `/review src/parser.py`，主输入框 **Enter 直接发送**展开后的任务。执行中发送同样命令会作为新的引导，经现有持久队列递送，并使未执行的旧提案失效；写文件、命令、图片发送等仍各自需要新的操作批准。模板不会授予权限或绕过只读模式。

TUI 输入 `/rev` 后按 Tab 选择，选择仅补全，不发送；再按 Enter 才发送任务。`/prompts [OFFSET]` 和 `uv run --locked sprig --list-prompts [OFFSET]` 只分页列出名称/说明，不调用模型；后者无需模型密钥。`--show-config` 显示模板元数据和设置来源，不显示正文。

一次性 CLI 也可使用模板，整个任务参数用当前 shell 的方式引用：

```powershell
uv run --locked sprig '/review src/parser.py'
uv run --locked sprig '/explain "src\目录 空格\main.py"'
```

模板只在用户提交处展开一次。完整参数 `$ARGUMENTS` 保留命令名后一个分隔字符之外的原文，包括换行与首尾空白；`$1` 至 `$9` 引用以空白分隔、可用单/双引号包围的参数，**反斜杠保持字面值**，不是 shell 转义。编号必须从 `$1` 连续到最大编号；未使用 `$ARGUMENTS` 时需要参数数量恰好匹配，拒绝缺参或多参。没有参数占位的模板会在正文后追加 `\n\n` 和参数，避免丢失用户要求。`$$` 输出字面 `$`；插入的参数不会继续解释占位符。

`$ARGUMENTS` 后应接空白、标点或正文结尾；上例用换行分隔。它不匹配后面紧接字母、数字、下划线或中文的更长标识文字。

模板内的 shell 片段、环境变量、`@路径` 都只是文字，不会在展开时执行、读取或附加文件。展开结果即使以 `/exit`、`/undo` 等开头，也作为普通任务正文发送，不递归执行本地命令。TUI `//review 原文` 发送字面 `/review 原文`；有字面粘贴标记的输入沿用既有数据语义，不作为模板。普通短粘贴是否折叠、是否标记字面，仍遵循[粘贴规则](tui-paste.md)。

定义仅来自明确加载的用户文件和所选 trusted profile；profile 按名称完整替换同名定义，并保留其他定义，`setting_sources` 标出每项来源。显式项目配置也不能添加模板；不自动扫描仓库或 home 的 Markdown，不切换模型、不运行脚本、不增加系统提示或模型工具。模板名限小写字母开头、后接小写字母/数字/`_`/`-`，最多 32 字符，不得覆盖内置命令。

最多 32 个模板，单模板正文最多 16 KiB UTF-8、说明最多 160 字节，库合计最多 48 KiB；配置本身仍受原 64 KiB 限制。拼接前累计 UTF-8 字节，重复参数也在生成超大正文前拒绝；编号解析只领取所需位置及必要的多参检查。展开后仍受单条输入和完整实际请求的原字节上限，失败不截断正文。TUI 参数、展开或完整封包预算错误保留原命令草稿；保存失败可用原文重试，不重复加入展开后的用户轮次。HTTP 已发送后的失败仍保留会话，需用户明确继续，不自动重试。

未使用的模板正文不进入请求或保存历史。调用后，历史、引导和私有保存记录展开后的普通用户正文，恢复不会重新解释旧命令；修改模板库不会改写旧任务。它们仍按现有凭据脱敏与会话隐私策略处理，不是加密存储。

当前验证使用合成任务与回环服务：三协议各 JSON/SSE 的六条正常 CLI 链完成读取、逐次批准编辑和独立固定检查；另六条拒绝编辑后保持原文件。80×24 TUI 覆盖补全、Enter、新引导、预算、保存失败重试、字面输入与元数据隐私。没有外部模型调用或新增任务成功率排名；远端 CI 继续冻结。

最终本地范围及未计入通过的初版检查见[机器记录](benchmarks/prompt-templates-20261024.json)。`/queue` 的正文仍按既有规则字面存储，不在任务启动/恢复时自动展开模板；需要时将完整任务正文入队。
