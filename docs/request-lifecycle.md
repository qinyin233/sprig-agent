# 模型请求总时限与取消

三种协议的普通 JSON、SSE、显式摘要请求，以及 CLI `--list-models` 元数据请求共用有界 HTTP 传输。请求大小、响应大小、完整结束校验和逐次工具批准仍各自生效；本地 `/models` 仍不发网络请求。

```toml
[providers.my_provider]
model = "your-model"
base_url = "https://your-provider.example/v1"
api_key_env = "YOUR_API_KEY"
request_timeout = 60
request_deadline = 300
```

`request_timeout` 是网络空闲/连接阶段上限，范围 `(0, 120]` 秒；省略时沿用命令的 `timeout`。`request_deadline` 默认 300 秒，范围 `(0, 3600]` 秒，是一次 HTTP 请求的总时限，包含等待响应头和读取正文。CLI 的 `--request-timeout`、`--request-deadline` 分别覆盖它们，`--show-config` 显示生效值和来源。配置只位于本地，不作为生成参数发送，不改变原有会话绑定。命令执行仍使用独立的命令超时。

总时限从本地封包完成、准备 HTTP 请求时开始，不在字节、注释、心跳、文本或工具参数到达时重置。因此服务每隔一小段时间发送一个字节，也不能一直占住该请求。超时用 `/usage` 的 `request_deadline` 分类记录；空闲超时仍为 `timeout`。默认不自动重试；明确配置的[临时 HTTP 重试](provider-retry.md)也让全部尝试和退避共享这一期限。超时、连接错误和半份响应仍需用户明确再次发送，不换模型或切协议。失败请求可能已经被服务接受，传输停止不等于远端停止计算或免除计费。

取消检查贯穿 TCP 连接等待、TLS 握手、代理 CONNECT、HTTP 响应头和正文/SSE 的网络等待。可轮询的等待每次最长约 100 毫秒，然后检查取消与剩余时限；这不是 UI 调度延迟的硬保证。接收轮询只重复等待数据，不重发请求。TUI 的 Ctrl+C 在没有文本输出时也能停止这些等待，保留尚未发送的输入；下一条 Enter 是新的明确请求。退出时继续等待当前 worker 停止，再关闭文件系统与会话句柄，不将网络工作交给脱离生命周期的线程。

传输没有在已超时的 `socket.makefile()` 缓冲流上继续读；该情形可能损坏缓冲状态，见 [Python socket 文档](https://docs.python.org/3.13/library/socket.html#socket.socket.makefile)。它用独立的原始接收器轮询，并持有标准 socket 文件引用，确保 urllib 释放连接所有者后，响应仍能安全读取、在结束时关闭。TLS 的证书验证、主机名验证与禁止重定向保持；代理沿用既有配置与标准库 NO_PROXY 规则。

流式文本只是暂时展示；三种协议都必须收到完整合法结束后才采纳助手消息、保存工具意图和进入审批。即使已经收到了看似完整的工具参数，缺少终止事件且总时限到达时，也不会批准或执行它。摘要请求取消不会应用检查点，已保存原文不变。

## 具体限制

- 系统 DNS 解析仍为同步调用，无法用此层强制中断；其耗时计入时限。解析返回后立即复查，若已取消或超时，不再建立连接或发送迟到的请求。没有留下可在后台继续 POST 的解析/网络线程。
- 正在发送请求字节的底层 `sendall` 由剩余空闲/总时限约束，取消最迟在该调用结束后检查，不能承诺大请求写入途中也在 100 毫秒内返回。失败写入的交付状态不明确，绝不重发这些字节。
- 连接和 TLS 握手各自受网络等待上限约束；TLS 内部握手进展不视为应用数据到达。此设置不是模型 token 窗口、总任务时长或费用上限。
- 已被服务接受的请求无法通过关闭本地 socket 保证远端撤销。已经完成并得到批准的早期工具动作也不会因后续网络超时而撤回。

## 验证

`tests/test_transport.py` 使用实际慢速 HTTP/TLS/代理连接，覆盖响应头与 JSON 滴入、SSE 心跳、无文本取消、TLS 握手静默、CONNECT 静默与真实隧道、证书拒绝、chunked SSE、三协议 HTTP/SSE、元数据和摘要取消。真实 Textual 应用覆盖无输出时取消、草稿保留、Enter 发送下一条、私有会话保存以及卸载时关闭 worker。TLS CA 与服务证书由开发依赖 `trustme` 在测试进程中临时生成；不提交证书/私钥，不安装系统 CA，运行时依赖没有增加。

本批完整测试、打包与精确提交 CI 记录见[机器报告](benchmarks/request-lifecycle-20261020.json)。本批是传输与交互可靠性验证，不据此声称模型任务通过率或摘要质量提高；适配验收不要求额外付费账号。
