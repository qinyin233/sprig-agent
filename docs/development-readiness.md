## 本轮验收范围

1. 用户只设置现有 `AGNES_API_KEY`，创建配置后可启动 TUI；未付费调用也能诊断本地配置。
2. 命名提供商确定实际模型、地址和凭据来源；错误字段、缺失环境变量、不安全文件或地址覆盖在发送前失败。不自动切换模型。
3. 配置内容不因日志、诊断、会话绑定、文件工具或子进程继承而直接泄露；命令仍明确不是沙箱。
4. TUI 命令保留各自审批和只读保护；新建对话不会覆盖原会话；执行中的本地命令不会意外变成模型任务。
5. 文件附件复用完整隐私检查、路径限制、取消与请求预算，明确是快照，不以静默截断代替完整内容。
6. 每个功能提交先通过本地完整测试；实质 OS 行为通过精确提交的原生 Windows/Ubuntu CI 后才记录跨平台结论。
