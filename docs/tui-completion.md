# TUI 命令补全与文件选择

主输入框保持 Enter 发送、Shift+Enter / Ctrl+J 换行。普通文本中 Tab 切换焦点；`@关键词` 后 Tab 打开[本轮文件选择](tui-mentions.md)。本地命令前缀按 Tab 打开命令选择器，例如 `/con`。↑↓移动，Enter 把命令填回输入框，Esc 关闭并保留原输入；选择本身不执行命令，再按一次 Enter 才执行本地操作。

`/add 关键词`、`/ref 关键词` 按 Tab 可模糊搜索文件并补齐参数。选择器保留工作区相对路径，支持中文、路径内部空格和反斜杠查询；替换参数后仍需 Enter 执行。多行草稿、执行中任务和批准窗内的 Tab 保持焦点导航，不弹出文件选择器。

## 直接选择上下文文件

点击输入框旁的“选择文件”，或输入 `/files`：

- 输入关键词，按文件名/路径查找；↑↓浏览候选。点击候选、按 Ctrl+Space 或“勾选/取消”可多选，再次操作取消勾选。跨查询保留已勾选路径，Ctrl+R 清空；空格仍正常输入路径查询。快捷键被终端或输入法拦截时，可点击勾选按钮。
- 已勾选时 Enter 或“添加实时引用”只添加勾选批次，不额外添加当前高亮文件；未勾选时沿用当前单文件。接到现有 `/ref` 后端。小文件在下一次模型请求前刷新；较大文件仍按原规则只附路径/大小。
- “附加快照”接到现有 `/add` 后端，保留选取时的完整有界文本。之后磁盘更改不修改快照。
- 这些操作不会请求模型，不会批准命令或写入；现有快照、引用、输出和完整请求预算继续生效。再发送一条普通消息才会调用模型。

打开选择器或直接添加文件不会清空未发送的任务草稿。二进制、隐私或预算检查失败时不附加不完整正文，保留原对话、引用选择和草稿。选择篮子最多 16 个文件、路径合计 8192 UTF-8 字节；已有实时引用也计入后端总数。查询中的候选仍最多 20 个，不是“全部搜索结果”。已勾选路径即使不在当前查询中仍会显示并提交；Esc 放弃整篮子。

最终批次使用现有一次性 `/add` 或 `/ref` 后端。任一读取失败、变为隐私路径、二进制、取消或总请求预算超限，都不提交部分对话/引用，草稿保留；成功后只做本地上下文更新，仍需发送普通任务才请求模型。快照不是跨文件原子读取，实时引用在请求前按既有规则复查。未提交的勾选不保存，成功的快照/引用随原私有会话机制保存，恢复不会自动请求模型。

路径本身含首尾空白时，参数补全保留原输入并提示改用“选择文件”直接添加，防止 slash 命令的既有空白裁剪指向另一个文件。直接选择传递原路径，不经文本参数解析。

## 扫描与隐私边界

候选枚举只读取文件名与类型，不读取文件正文。唯一读取的工作区规则文件是原有 `.sprigignore`。沿用敏感目录/文件、配置文件、额外排除模式和符号链接/重解析点限制，同时跳过 `node_modules`、`.venv`、`.venv-*`、`__pycache__`；路径中已知配置凭据及终端控制字符不会进入候选。

每次最多检查 5,000 个目录条目、深度 32、250 毫秒扫描预算，保留至多 20 个匹配候选。期限在条目边界检查，不是操作系统 I/O 的硬实时保证。达到扫描或显示上限会提示细化查询；空结果不能证明整个仓库没有这个文件。

文件查询最长 256 字符，输入有 150 毫秒去抖。查询变化立即使旧结果不可选，后台结果按查询代次校验；关闭弹窗取消扫描。后台扫描与已有 worker 共用工作区句柄生命周期锁，在锁外向 UI 投递结果，避免关闭句柄或等待 UI 形成竞态。

`read_file` 或 `list_files` 禁用时不枚举候选。选择后的实际读取还会重新校验当前路径、隐私、UTF-8、大小和预算；候选不是读取凭据、当前文件内容或写入授权。只读模式可以选择合规上下文文件，不因此启用命令和修改。

本批完成命令菜单、`/add` / `/ref` 参数补全与本地文件选择器；后续补充[普通消息中的内联 `@` 元数据](tui-mentions.md)及[长文本粘贴折叠](tui-paste.md)。后续小批次增加了直接选择器的跨查询多选；命令、`/add` / `/ref` 参数补全和内联 `@` 仍单选。图像/PDF 和全仓库索引缓存仍待后续。没有新增配置项、运行依赖或模型工具定义。
