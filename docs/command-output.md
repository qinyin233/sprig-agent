# 长命令输出：执行上限与展示预算

命令默认允许采集 **1 MiB** 原始 stdout/stderr 合并输出，展示正文仍受 `max_output` 限制（默认 16000 个 UTF-8 字节）。超过展示预算时保留有界首尾和省略标记，命令可执行到末尾，返回最终诊断及真实退出码；检测到超过采集上限时仍停止进程树，标记 `output_limited=true`。无需为了长构建或测试日志把完整正文放进模型上下文。

可以在用户配置或 profile 中调整两个独立预算：

```toml
[execution]
max_output = 16000
output_limit = 1048576
```

上例允许采集至多 1 MiB 原始 stdout/stderr 合并输出，检测到超出时停止进程。送给模型的 `output` 正文保留开头和结尾，并用省略标记连接，UTF-8 正文预算为 16000 字节。命令可执行到末尾，让最后的错误、测试统计和退出码返回修复流程。正文之外仍有 JSON 字段和消息封装开销，整个请求仍受原上下文预算检查。

CLI 对应 `--command-output-limit 1048576`；其优先级高于 profile 和用户 TOML。`--show-config`、TUI `/config` 展示实际 `execution.output_limit` 及 `command_output_limit` 的设置来源。Schema 和完整示例同步支持；项目配置不能修改 execution，不能借仓库文件扩大执行预算。

`output_limit` 为 0 或 256–8388608 的整数，最多 8 MiB；未设置时为 1048576。**0 明确恢复旧行为：采集到 `max_output` 后检测超限并停止，而不是不限制输出。** 可用 `--command-output-limit 0`，或 `[execution] output_limit = 0`。Python API 中显式传入 `None` 也保留旧行为。只有采集上限大于展示预算时启用首尾展示；也可显式设置比展示预算更低的采集上限。文件读取、附件、编辑大小和模型回复上限不随之扩大。

此前未显式设置采集上限的保存会话没有该绑定字段。新默认会在联系模型前拒绝恢复，并提示 `--command-output-limit 0` 和原来的 `--max-output` 值；不会静默修改旧会话或发送历史。已有显式上限的会话仍须保持相同数值。旧会话若要采用新默认，请明确新建会话；没有自动迁移或动作重放。

## 如何判断命令是否完成

| 字段 | 含义 |
| --- | --- |
| `returncode` | 实际进程退出码；超时或强制停止仍需结合下面的状态判断 |
| `output_limited` | 检测到超过原始总输出上限并停止进程；验收不能据此通过 |
| `timed_out` | 达到命令超时；验收不能据此通过 |
| `output_truncated` | 首尾模式省略了展示正文的中间部分；本身不表示进程被停止 |
| `output_bytes` | 首尾模式采集并交给输出处理的原始字节数，最多为总输出上限 |
| `output_omitted_bytes` | 脱敏后的 UTF-8 正文中未展示的字节数；不包含省略标记 |

后三个字段仅在首尾模式下提供。只有命令完整结束、退出码为 0、且没有超时、输出上限或其他不确定状态时，应用的固定验收才可能通过。展示省略不替代实际检查，阶段检查也不替代独立最终验收。

需要解析完整文本的内部流程有更严格的条件：工作树管理遇到 `output_truncated=true` 就停止，不把首尾预览当成完整 Git 元数据。回归已复现省略区间隐藏本地 include 后仍创建工作树的情况；修正后在解析前停止，不创建目标。这里的停止不表示原 Git 命令执行失败，也不把展示省略一律当作固定验收失败。

## 隐私、取消和资源边界

每个命令仍需一次新批准；批准界面同时显示原始输出上限、展示预算和首尾模式。只读、工具禁用、工作目录、环境过滤、超时、取消、POSIX 进程组和 Windows Job Object 清理继续执行。默认及显式总输出上限都加入新会话的绑定；恢复时更改或去掉该数值会拒绝复用原会话。后台命令也使用该采集上限，原有每项最多 1 MiB 脱敏输出内存保留限制独立存在。

UTF-8 解码和已知凭据脱敏在选择首尾之前连续进行，包含跨管道分块的密钥；这样省略边界不会把完整密钥切成无法匹配的片段。展示边界不切出无效 UTF-8，终端控制字符仍转成可见表示。输出开头可立即展示，末尾在命令结束或停止后补齐，省略量如实报告。

执行层仍可能在进程内存保留至多总输出上限的原始字节；首尾缓冲合计不超过 `max_output` 的 1.5 倍，另有当前分块和解码/脱敏状态。超出展示预算的完整日志不会由此写入工作区或持久化会话，保存的工具正文是脱敏后的有界结果。现有命令权限允许的文件/网络副作用仍由用户审阅批准；这项配置不提供操作系统沙箱。

现在也可另行配置[私有命令日志保留](command-logs.md)，按会话句柄回查展示中省略的中间文本。它默认关闭、在命令批准中列明，日志正文不复制进会话 JSON；原始输出停止上限仍保持，未采集到的内容无法恢复。
