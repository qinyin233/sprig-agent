# 只读调查

遇到陌生模块时，Sprig 可以将局部代码调查交给 `explore`，让主对话保留实现所需的上下文。参考了 OpenCode 将子任务放在独立会话并检查调用权限的做法。[OpenCode 固定版本源码](https://github.com/anomalyco/opencode/blob/9d90d892dcbfc52b47e95b2ea31b8aba877128fd/packages/core/src/tool/plugin/subagent.ts)

在可信用户配置或 profile 中开启，默认关闭。

```toml
[execution]
explore = true
```

模型提议时，审批界面显示调查任务、工作区相对目录、当前模型与服务地址，以及最多 1–3 次额外请求。每次请求的截止时间取当前设置和 60 秒中较小者。每轮最多弹出一次调查审批，拒绝后消耗 0 次子任务请求。`[tools] explore = false` 可以禁用此工具。

子任务使用当前模型和协议，带上调查描述和已有的项目规则。规则包括配置指定的文件，以及启用自动发现时的祖先和调查目录 `AGENTS.md`。普通源码读取从审批时打开的目录句柄开始，遵守工作区隐私规则和工具禁用。子任务可使用文本 `read_file`、`list_files`、`glob`、`grep` 和 `project_map`。最后一次请求只生成调查报告，读取源码需要至少两次请求的额度。

主对话收到有界调查结论和请求次数。原始子任务上下文仅在内存中，模型用量计入主会话。执行期间可以取消或提交下一条引导，排队引导在调查返回后由主对话处理。需要改动时，先由主任务核对源码，再通过原有流程逐次批准写入或命令执行。
