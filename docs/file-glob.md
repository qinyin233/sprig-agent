# 按文件名发现路径

模型可用只读 `glob` 在当前工作区内寻找文件名，适合已知名称、扩展名或目录模式时先定位，再用 `read_file` 读取。它只枚举名称并读取有界隐私策略；候选文件正文不打开，也不调用命令、网络、解析器或额外模型。二进制、图片、无效 UTF-8 正文和大文件也可只枚举安全路径；读取内容仍由后续工具独立检查。

```json
{"pattern":"**/exceptions.py"}
{"pattern":"src/**/*.py"}
{"pattern":"package/*.py","path":"src"}
{"pattern":"*.toml","hidden":true,"limit":50}
```

## 模式与范围

`path` 默认 `.`，是工作区内的相对 POSIX 目录；Windows 也使用 `/`。模式相对于这个目录匹配，返回路径始终相对于工作区。单个组件的模式（如 `*.py`）在所有深度匹配文件名；`*`、`?`、`[ab]`、`[!a]` 遵循现有 `FileGlob` 语义，整个路径组件 `**` 可以跨零层或多层目录。含目录前缀的模式会剪掉不可能匹配的子树。

所有平台都区分大小写，不做 Unicode 归一化、路径纠错或 shell/变量展开；文件名按实际名称返回。模式最多 256 UTF-8 字节、32 个组件；绝对/驱动器模式、反斜杠、`.` / `..` / 空组件、整式 `!` 排除和控制字符会拒绝。不提供大括号或 extglob 展开。

默认 `hidden=false` 跳过遍历中遇到的点名称；显式将安全的点目录设为 `path` 时可以查其中的普通文件。`hidden=true` 允许普通点文件和目录参与匹配，隐私规则仍生效。遍历时跳过 `node_modules`、`__pycache__`、`.venv` 和 `.venv-*`；这些噪声目录可由用户明确设置为起始 `path`，不会解除隐私或路径限制。

## 结果和预算

```json
{"files":["src/requests/exceptions.py"],"entries_scanned":44,"truncated":false,"timed_out":false,"skipped_entries":0}
```

默认返回最多 100 个文件，`limit` 为 1–1000 的整数。只返回普通文件名；链接、Windows reparse point、POSIX FIFO 等不进入结果。展示按路径排序；受限时保留的是遍历中已观察到的子集，不保证全树字典序前几项，也没有稳定分页游标。

完整 JSON 不超过 `min(max_output,16384)` 字节；遍历最多 5000 个目录条目，递归深度最多 32。约 1 秒是合作式时间预算，在遍历与发布检查的边界复查，不能抢占一次阻塞的系统调用。超限或无法访问的子树会保留有界结果并标记 `truncated`，时间耗尽还标记 `timed_out`；I/O 失败计入 `skipped_entries`。检查这些标记，再缩小 `path` 或模式；部分扫描的空数组不表示整个工作区不存在该文件。取消直接终止，不返回部分列表或启动模型请求。

## 权限、隐私与后续动作

路径通过已有 pinned directory 和 no-follow 目录能力遍历，受到 `.sprigignore`、`files.exclude`、活动配置路径以及内置敏感名称规则约束。发布前重读隐私规则，过滤新排除项、包含已配置凭据或匹配内置凭据形状的文件名；控制字符、反斜杠、超过 4096 UTF-8 字节及无法安全编码的路径不返回。文件正文即使包含凭据也不会被这个工具读取或上传，但普通名称不证明正文可以安全读取。

`[tools].glob=false` 或 `--disable-tool glob` 同时从模型定义和实际执行层禁用。`list_files=false` 也禁用 `glob`，项目层不能绕过可信设置重新开启。只读模式可以使用它；禁用 `read_file` 不禁止原有的目录名称权限。

结果是文件名的历史观察，没有 `read_id`、内容摘要或授权。后续读取重新检查路径、隐私和内容，修改仍需有效读取版本和新批准。文件可能在观察后移动、消失或被替换；不自动打开猜测的路径。默认会话绑定在离线对照中保持一致，`glob` 纳入检查计数和明确启用的历史压缩；计数与文件名都不能代替固定验收。

CLI 和 TUI 使用同一模型工具。TUI 仍以 Enter 发送任务和中途引导，`glob` 无需写入批准；实际编辑和命令照常逐次批准。

## 验证范围

新增 18 项测试包含真实文件/隐私更新、受保护、已配置凭据与未配置的凭据形状名称、输出与条目/深度/时间预算、取消、子树剪枝、POSIX 链接/FIFO 和 Windows junction。三协议各 JSON/SSE 的正常链路完成发现→读取→批准编辑→独立验收，80×24 Textual 通过 Enter 发起只读发现和读取。原 16 KiB 请求预算和 4932 字节工具定义硬门槛保持；当前默认工具定义为 4894 字节（原 4927）。基本系统提示由 2524 降至 2372 字节，提示与只读定义合计由 5231 降至 5169 字节。初稿因 5433 字节的说明与新增定义触发回退，恢复读取窗口、正则超时/换行/折叠语义的明确说明后重新冻结验证；模式、类型、数量和权限仍由后端校验，不依赖模型声明。

最终冻结后，本地完整回归各 1638 项：Windows 1616 通过、22 项平台跳过（842.286 秒），WSL 1614 通过、24 项跳过（609.176 秒）。Windows Python 3.11 的新增 18 项为 17 通过、1 项 POSIX 跳过；150 项针对性回归为 147 通过、3 项跳过。两套 SDK 环境在两端各 30 项无跳过通过。平台跳过与本地 WSL 均不等于远程原生 CI 通过。

同一 Requests 初始快照的离线探针中，旧提交不提供此工具；新实现扫描 44 个条目后找到 `src/requests/exceptions.py`，原错误路径仍被拒绝。它是确定性工具探针，不是模型自行选择 `glob` 的回放，也不证明减少真实模型轮次或提高成功率。本批没有外部模型请求，已有 Requests/Click 的真实结果保持。最终数值和源码身份见[本批记录](benchmarks/file-glob-20261028.json)。远程 CI 在 2026-11-01 前冻结，恢复前仍须核实账户限制和此前门禁。
