# 向用户澄清需求

交互式 TUI 和终端 CLI 提供 `question` 工具。模型可以在需求不明确时询问用户，收到全部答案后再继续。默认非交互调用不提供这个工具，不会停在管道 stdin 上等待回答。

## 终端操作

TUI 每页显示一题：↑↓ 高亮，Space 切换选取，Enter 明确确认当前题，也可填写自定义答案。单选题的自填内容替代选项，多选题可同时选择选项和自填。上一题保留选取和草稿；提交全部题目后才将答案交给模型。较长题干可以聚焦问题区滚动，80×24 终端也能滚动表单。

Esc 或关闭按钮结束本轮，等待新输入；Ctrl+C 取消任务。Ctrl+L 聚焦问题中的新要求输入框，Enter 发送后关闭旧问题，模型根据新要求调整。主输入草稿不被表单覆盖。问题和引导字段只接收单行文字，多行或超长粘贴整段拒绝，原有输入保持；可以 Esc 关闭后在主输入中粘贴多行或大文本。

交互式 CLI 使用从 1 开始的选项编号；多选可输入 `1,2`，自填使用 `: 自定义内容`，组合可用 `1,2,: 补充内容`。没有选项的题可直接输入文字。空行不会默认选中，非法答案会提示重输；`/cancel`、EOF 关闭问题，Ctrl+C 取消任务。

## 配置与边界

```toml
[tools]
question = true
```

默认允许，但只有安装了交互回调时才会提供给模型。`question=false` 或 `--disable-tool question` 同时禁用 schema 和执行入口。只读模式允许澄清。非交互嵌入可显式传递 `Tools(config, approve, ask=callback)`；回调接收已校验、脱敏的题目列表，返回 `list[list[str]]` 或 `None`。核心仍会重新校验回调答案，不信任界面返回值。

每次 1–3 题，每题最多 6 个选项；标题 30 字符、题干 512 字符、选项名 64 字符、说明 160 字符。完整题目 JSON 最多 8192 UTF-8 字节。每个答案最多 2048 字符，完整结果同时受 8192 字节和 `max_output` 限制。预算按实际 JSON 编码计算，Unicode 不被切半；重复答案、非法控制字符或不完整答案被拒绝。TUI 超出答案预算时保留草稿，可返回前题缩短。

问题是需求和偏好的收集入口，不能用于收集密钥或批准操作。结果使用 `answered` 与 `not_authorization`，不产生 `approved=true`。同一模型回复若包含问题，其他工具提案全部跳过，包括排在问题之前的提案；多个问题调用只显示第一个。回答后必须通过新模型回复重新提出操作，再走逐次批准、版本复查和独立验收。回答“yes”不能批准文件写入、命令或固定检查。

关闭、无交互回调或答案无效时停止当前轮，不猜答案或自动继续模型调用。问题期间发出的新要求可触发重新规划；旧提案仍不执行。完整响应/SSE 校验通过后才显示问题，截断的工具参数不会弹表单。提问本身不额外请求模型，答案后的继续调用遵循普通步数与上下文预算。

未完成表单和部分草稿不保存、不发送。完整答案进入下一次供应商请求，以及已启用保存的私有明文会话；已知凭据在展示和写入历史前脱敏，未知隐私无法自动识别。恢复会话不会重弹旧问题或重放工具；提问等待在运行状态中单独标记，不与操作审批混淆。

## 验证范围

三协议均通过实际回环 HTTP/SSE 验证“问题→人类答案→下一次请求”，包含截断不弹窗、兄弟提案跳过和新批准。界面回放覆盖单选、多选、自填、回退、取消、退出、恢复、中途引导、小终端、滚动题干和粘贴保真。固定回复用于验证协议与程序行为；不据此推断模型编码成绩。

本批采用 `[skip ci]` 节省 Actions 额度，没有该批远程 CI。最终本地测试、安装包与源文件摘要见[机器记录](benchmarks/questions-20261020.json)。没有更改原生进程或文件句柄实现，不将本地 WSL 结果当作原生 Ubuntu runner 验证。当前没有后台问题收件箱、持久表单草稿或服务端协作表单。
