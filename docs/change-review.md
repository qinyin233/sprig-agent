# 审阅保留的文件修改

TUI 侧栏“审阅文件修改”或 `/changes review` 打开只读审阅窗口。用列表选择记录、Enter 查看，按钮翻页，Esc 关闭。主输入草稿、文件选择和折叠粘贴保持；窗口正文的 Enter 不发送任务。

连续 chat 使用：

```text
/changes review
/changes show latest
/changes show RECORD_ID
/changes show RECORD_ID NEXT_OFFSET SNAPSHOT
```

`/changes` 原有备份元数据列表保持。`review` 在 chat 中列出可见记录，`show` 返回一个 JSON 页面；后续偏移与 `snapshot` 使用上一页返回值，偏移单位是字符，UTF-8 和 JSON 封包字节另行检查。TUI 处理这些分页参数，可上一页、下一页、重新读取。

## 数据范围

审阅覆盖**当前工作区已经加载并保留的文件备份**，包括精确编辑、新建、删除、移动及明确选择的前台命令备份。最多 16 条、合计 4 MiB，默认只在当前进程。显式 `--change-history-dir` 使用私有持久化机制。记录淘汰或丢弃后无法再查。[前台命令备份](command-output.md#备份前台命令涉及的文件)

审阅不读取 Git diff、启动命令或模型，也不会自动把差异放进对话。未指定备份的命令改动、目录创建和完整 Git 工作树仍在这份记录之外。`/diff` 与工作树管理各有独立流程。

列表显示保留记录的应用/撤销/不确定状态和路径预览；路径预览过长会明确标记。页面显示所选记录本身的前后差异，不把后来同路径的其他修改混进该记录。空文件创建与删除也有明确说明。

## 当前文件与验收

页面另外观察当前文件，比较**该路径最近记录的完整内容及文件身份**。状态包括符合最近记录、存在记录外变化、父目录不可用，以及有未结算改动。相同内容的外部文件替换也不被解释成同一文件。

这次观察不代表固定验收，也不能保证文件之后不变。审阅不产生或重新确认验收结果，不修改备份和工作区，不授予撤销或模型动作权限。`/undo`、`/redo` 仍只按原栈顺序逐次确认完整 diff，并重新检查字节、身份、隐私和取消；恢复后需明确 `/verify` 或正常任务重新验收。

## 大文本、隐私和过期页面

单条备份仍受原 512 KiB 文件上限约束。比较采用唯一行锚点和有序子序列，歧义区间按完整替换展示；避免在重复大文件上做平方复杂度匹配，差异**不保证最小形式**。普通 LF 示例经过独立 Git 补丁检查，但本窗口是审阅展示，**不作为自动应用补丁的入口**。

前后快照在添加差异前缀前整体脱敏，格式化后再次保护；控制字符、Tab、CR、BOM 和双向控制符以可见转义展示。显示行号据处理后的文本生成，脱敏可能改变布局，不能当作编辑 `read_id` 或原始文件行位。每页完整 JSON 不超过 `min(max_output, 16384)` 字节；安全比较有 8 MiB 字符硬上限，预算不足会明确拒绝，不把缺失尾部当读完。

每次请求都检查工作区归属、打开的根/私有日志句柄、读取工具开关、当前隐私规则、凭据集合、备份快照和当前文件。受保护记录不展示；二进制/非法 UTF-8 等现有文本限制保持。分页绑定安全差异和观察状态；来源变化时拒绝旧快照，TUI 清空旧页，用户重新读取。历史差异是数据，其中的斜杠命令和提示不执行。

读取或渲染期间取消、失败及新引导不触发模型请求。新引导继续保留，关闭审阅后明确“继续”才递送；原会话文件不因审阅改写。应用不自动恢复未结算改动或清理备份。

## 验证范围

18 项新回归包含精确文件/日志不变、外部替换、未结算记录、跨工作区与关闭资源拒绝、动态隐私/凭据/抓取竞态、完整分页、150 组独立重建、50,000 行重复输入、取消和普通多块差异的独立 Git 检查。80×24 Textual 验证选择、翻页、草稿、清屏及明确继续。三协议各 JSON/SSE 六条实际 CLI 回环链完成修改→审阅→撤销→重做→独立固定检查；审阅没有增加模型请求。

这些是合成夹具与本地回环的程序证据，没有外部模型调用或新的编码质量结论。最终范围与隔离反例见[机器记录](benchmarks/change-review-20261025.json)。2026-11-01 前不触发 Actions，远程 CI 待解禁验证。
